# 仓库目录说明

这份目录图按仓库当前受 Git 管理的文件整理，方便组员找需求、代码、测试和部署入口。运行程序后生成的数据库、缓存等本地文件不列在这里。

## 项目目录图

```text
.
├── .github/workflows/           GitHub Actions 检查和部署流程
├── backend/
│   ├── campus_app/              FastAPI 后端应用
│   │   └── routers/             按认证、M1、M2、M3 和共享管理划分的 API
│   ├── migrations/              Alembic 数据库迁移
│   └── tests/                   API 与业务流程测试
├── demo/                        浏览器演示页面（HTML、CSS、JavaScript）
├── deliverables/                课程展示材料
├── docs/                        需求、架构、评审和实现说明
├── optional-agent/
│   └── dsh-campus-resource/     可选 DSH 插件源码，不是核心平台运行依赖
├── scripts/                     检查和数据库维护脚本
├── Dockerfile                   容器镜像构建配置
├── compose.yaml                 本地多服务与数据库配置
├── compose.prod.yaml            生产环境 Compose 配置模板
├── pyproject.toml               Python 项目依赖和工具配置
├── uv.lock                      锁定后的 Python 依赖版本
└── README.md                    项目介绍、运行方法和入口索引
```

## 代码入口

### 后端

后端使用 FastAPI，业务代码位于 `backend/campus_app/`。

| 文件或目录 | 用途 |
| --- | --- |
| `main.py` | 创建 FastAPI 应用并挂载路由。 |
| `routers/auth.py` | 登录、会话和账号接口。 |
| `routers/m1.py` | 座位查询、预约、签到和取消接口。 |
| `routers/m2.py` | 教室申请与审批接口。 |
| `routers/m3.py` | 报修、派单、维修和验收接口。 |
| `routers/shared.py` | 房间、座位、通知、审计等共享管理接口。 |
| `domain.py` | 预约冲突、审批、占用和工单等业务规则。 |
| `models.py` | SQLAlchemy 数据表模型。 |
| `schemas.py`、`views.py` | 请求校验结构和 API 返回数据组织。 |
| `rbac.py`、`dependencies.py`、`security.py` | 权限、请求认证和凭据安全处理。 |
| `resource_client.py`、`resource_service.py` | M2 终审调用独立 D 资源进程的 HTTP 链路。 |
| `worker.py` | 预约提醒、审批超时和维修 SLA 等后台任务。 |

### 前端、数据和验证

- 浏览器演示页面在 `demo/`；主页面是 `demo/index.html`，房间签到屏幕是 `demo/screen.html`，交互逻辑和样式在同目录的 JavaScript 与 CSS 文件中。
- 数据库表结构及版本迁移在 `backend/migrations/`；SQLite 用于本地开发，Compose 配置 PostgreSQL 服务。
- 行为测试在 `backend/tests/`；测试配置、运行依赖和 Ruff 设置在 `pyproject.toml`。
- `scripts/` 放辅助检查和数据库恢复脚本；`.github/workflows/` 放 GitHub Actions 流程。

## 当前技术栈

| 部分 | 当前使用 |
| --- | --- |
| 后端 API | Python、FastAPI、SQLAlchemy |
| 数据库结构管理 | Alembic；本地 SQLite，Compose 使用 PostgreSQL |
| 浏览器页面 | HTML、CSS、JavaScript，位于 `demo/` |
| 依赖与开发工具 | `uv`、pytest、Ruff |
| 可选集成 | `optional-agent/dsh-campus-resource/` 是自然语言 Agent 的候选 DSH 插件；核心平台不依赖它，且不能据此说插件已安装或运行。 |

## 汇报时可以这样指路

- “需求写在 `docs/`，重点看详细需求文档和产品需求规格说明书。”
- “系统结构在 `docs/architecture.md`；共享信息如何约束看治理文档，具体代码实现看实现说明。”
- “前端演示页面在 `demo/`，后端 API 和业务逻辑在 `backend/campus_app/`，数据库迁移在 `backend/migrations/`，行为测试在 `backend/tests/`。”
- “核心后端框架是 FastAPI；DSH 插件在 `optional-agent/`，属于课程附加项，不是主平台依赖。”
